**Overview of App:**

This project is a machine learning (ML) Streamlit interactive app. On this application, users can upload their own dataset file (in CSV form) or use the sample dataset that has already been uploaded into the app (the famous Iris dataset!). Once you do this, you can train and test the data, set your test set size, model hyperparameters, the number of minimum sample splits and your criterion, and it will return with a confusion matrix model and a decision tree model, all of which will teach you how ML works!

**Link to Deployed App:**

Here is a link to the deployed app itself: https://egbuonu-data-science-portfolio-flower.streamlit.app/

**How to Run App Locally:**

Here are the instructions for how to run this app locally. Please ensure to follow it in these exact steps.

1) cd MLStreamlitApp
2) pip install -r requirements.txt
3) streamlit run app.py
