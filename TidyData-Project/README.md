## Project Overview:
The goal of this project was to gain hands-on experience with tidy data and data cleaning. With this goal, I completed a notebook on the 'Mutant Moneyball" dataset and applied the principles of data cleaning and tidy data to derive findings and visualize the data in an organized manner that allows for deeper understanding of the dataset itself. For this project, the principles of tidy data were of great influence, with these principles being:

Each variable is in its own column 
Each observation forms its own row.
Each type of observational unit forms its own table (Wickham, 2014)

To simplify the principles, tidy data is largely based on the idea of making sure the variables, observations, and observational unit have their own and correct place, such as variables being in vertical form in columns and observations being in horizontal form in rows, and are not placed in an inaccurate or unorganized manner. In real-life application, tidy data ensures that those working with the data, such as data engineers or scientists, can being their work through having the data cleaned, organized, and ready for analysis.
